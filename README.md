# توفير هب — موقع أكواد الخصم

موقع عربي أصلي بفكرة تنظيم حسب المتجر (مش نسخة من أي موقع).
التركيز: نون، مع أقسام ديفاكتو ونمشي وممزورلد.

## تشغيل محلي
افتح `index.html` مباشرة، أو شغّل سيرفر بسيط:
```bash
python3 -m http.server 8000
```
ثم افتح http://localhost:8000

## تعديل الأكواد
كل الأكواد في `codes.json`. عدّل:
- `store`: noon-egypt / noon-ksa-uae / noon-gcc / defacto / namshi / mumzworld
- `code`: الكود نفسه
- `title` و `description`: اكتب نسبة الخصم الرسمية فقط، بدون مبالغة
- `expiry`: تاريخ الانتهاء الحقيقي
- احذف أي كود متوقف فورًا

## قبل النشر
1. غيّر `https://example.com/` في `index.html` و `robots.txt` و `sitemap.xml` إلى دومينك الحقيقي.
2. غيّر الاسم لو اخترت اسمًا نهائيًا غير "توفير هب".
3. ضع روابط الأفلييت الرسمية الخاصة بك بدل الروابط العامة.
4. حدّث تاريخ "آخر تحديث" في الصفحة مع كل مراجعة.
5. للنشر على GitHub Pages: ارفع الملفات إلى repo ثم فعّل Pages من Settings.

## ملاحظة أمانة المحتوى
لا تدّعي نسب خصم غير مؤكدة، ولا تنسخ نصوص أو تصاميم مواقع أخرى.
حدّث الأكواد دوريًا حتى يثق فيك الزوار ومحركات البحث وأدوات AI.
