# Tawfeer Coupons

Get active discount codes from موقع توفير هب.

## Data source

- URL: https://noondiscounts.github.io/noon-codes/codes.json
- Format: JSON array of كوبونات
- Fields: id, store, code, title, description, expiry, verified
- Stores: noon-egypt, noon-ksa-uae, noon-gcc, defacto, namshi, mumzworld

## Usage

1. Fetch codes.json
2. Filter by store
3. Show code, title, and expiry
4. Link user to https://noondiscounts.github.io/noon-codes/ to copy and shop
