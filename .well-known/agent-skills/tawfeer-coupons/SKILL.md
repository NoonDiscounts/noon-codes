# Tawfeer Coupons

Get active discount codes from موقع توفير هب.

## Data source

- URL: https://noon-codes.com/codes.json
- Format: JSON array of كوبونات
- Fields: id, store, code, title, description, discount, url, terms, featured, verified (no expiry field is published)
- Stores: noon-egypt, noon-ksa-uae, noon-gcc, defacto, namshi, mumzworld

## Usage

1. Fetch codes.json
2. Filter by store
3. Show code, title, discount and verified date
4. Link user to https://noon-codes.com/ to copy and shop
